# Results included in this repository

`supplementary/` contains the compact machine-readable evidence package used by the manuscript, including Tables S1-S7, Methods S1, field dictionaries, manifests, checksums, and audits.

`figures/` contains the current supplementary figure exports. Large matrices, source expression objects, model caches, and intermediate workflow directories are intentionally excluded from Git.

The result files are a frozen snapshot. Regenerated outputs should be written to a new versioned directory and compared by checksum rather than overwriting this snapshot.
