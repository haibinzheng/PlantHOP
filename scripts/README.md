# Script inventory

The scripts in this directory are an executed-workflow snapshot, not a polished software package. They are retained with their versioned names so that supplementary tables and manuscript methods can be traced back to the corresponding analysis stages.

Scripts that provide `--help` or positional command-line interfaces should be preferred for new runs. Frozen scripts with embedded paths should be treated as provenance artifacts until the shared path-configuration refactor is complete. No script should be run against source data with write permissions.
